# La tesis — Implementation Plan (fase 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que una campaña despache a un agente la creación de una implementación nueva —una feature, un modelo— dentro del proyecto del usuario, la ejecute, la puntúe con un evaluador que el agente no puede tocar, y deje el linaje para revisarla.

**Architecture:** Cuando el objetivo se estanca, el orquestador copia el workload a `<campaign_dir>/variants/<variant_id>/` y despacha ahí una tarea a un agente **con herramientas reales y cwd en la copia** — no una llamada one-shot que devuelve archivos en JSON. Lo que el agente escribió se verifica *después*: se compara el árbol de la variante contra el original, y todo cambio fuera del allowlist descarta la variante. Los trials de esa ronda entrenan desde la copia, pero **evalúan desde el árbol original**, así que el código que el agente escribió nunca es el que produce el número.

**Tech Stack:** Python ≥3.10, pydantic v2, pytest, subprocess, `filecmp`/`difflib`.

**Spec:** [docs/superpowers/specs/2026-09-15-campanas-de-mejora-verificables-design.md](../specs/2026-09-15-campanas-de-mejora-verificables-design.md)

**Depende de:** [2026-09-15-circuito-honesto.md](2026-09-15-circuito-honesto.md), completo y con su puerta de salida verificada. Sin `IAX_RESULT`, sin las dos fases y sin el `IAX_WORK_DIR`, este plan no tiene dónde apoyarse.

## Global Constraints

- Python `>=3.10`. Pydantic v2.
- El allowlist `editable_paths` **deja de tener default permisivo**: hoy `[]` significa "todo editable" (`improve/variants.py:99`), y esa línea compuesta con un agente que puede escribir el número es el agujero que ordena el spec entero.
- Con un agente que tiene herramientas, el control de caminos ya no puede ser de *escritura* (`resolve_edit_path` no ve lo que hace `Write`): pasa a ser de *verificación*, comparando árboles después.
- Prompts y salida de campaña son **no confiables**: nunca se interpolan en un string de shell. El brief va por stdin o por argumento del CLI del agente, nunca por `shell=True`.
- Nada de este plan modifica el árbol de trabajo del usuario. Las variantes viven bajo `<campaign_dir>/variants/`.
- El evaluador y los datos de test están fuera del mandato del agente, estructuralmente y no por prompt.
- `variants.enabled` sigue en `False` por default.
- Suite de referencia: `.venv/bin/python -m pytest -q -m 'not integration' --ignore=tests/test_server.py` verde al cerrar cada tarea.

```python
# ai_experiments/schemas.py
class VariantSpec(ConfigModel):
    """Whether, and how far, the loop may change the workload's own code.

    Off by default: a loop that edits code without being asked is a surprise.
    Turning it on requires saying which files are in scope, because the
    permissive default — every file, including the evaluator — put the agent's
    own scoreboard inside its reach.
    """

    enabled: bool = False
    source_dir: str | None = None
    #: Glob allowlist for the files a variant may change. Required when
    #: enabled: there is no safe "everything".
    editable_paths: list[str] = Field(default_factory=list)
    #: Globs that stay out of scope even if the allowlist matches them.
    protected_paths: list[str] = Field(default_factory=list)
    smoke_command: list[str] = Field(default_factory=list)
    smoke_timeout_seconds: int = 120

    @model_validator(mode="after")
    def scope_is_explicit(self) -> VariantSpec:
        if not self.enabled:
            return self
        if not self.editable_paths:
            raise ValueError(
                "variants.editable_paths is required when variants are enabled: "
                "an empty allowlist would put every file in scope, the "
                "evaluator among them"
            )
        if not self.smoke_command:
            raise ValueError(
                "variants.smoke_command is required when variants are enabled: "
                "a variant that cannot start wastes the whole round"
            )
        return self

    def allows(self, relative: str) -> bool:
        if any(fnmatch(relative, pattern) for pattern in self.protected_paths):
            return False
        return any(fnmatch(relative, pattern) for pattern in self.editable_paths)
```

```python
# ai_experiments/improve/variants.py
def read_tree(root: Path) -> dict[str, bytes]:
    """Every file under ``root``, by relative path, skipping the noise dirs.

    Public because `lineage.variant_diff` reads the same two trees to render
    the change a person reviews.
    """
    files: dict[str, bytes] = {}
    for path in root.rglob("*"):
        if not path.is_file() or path.is_symlink():
            continue
        relative = path.relative_to(root)
        if any(part in SKIP_DIRS for part in relative.parts):
            continue
        files[relative.as_posix()] = path.read_bytes()
    return files


def changed_paths(record: VariantRecord) -> list[str]:
    """What the variant changed against the tree it was copied from.

    Content, not timestamps: copying a tree rewrites every mtime, so anything
    time-based would report the whole project as changed.
    """
    source = read_tree(Path(record.source_dir))
    variant = read_tree(Path(record.root))
    changed = {
        path
        for path in set(source) | set(variant)
        if source.get(path) != variant.get(path)
    }
    return sorted(changed)


def verify_scope(record: VariantRecord, spec: VariantSpec) -> list[str]:
    """The changed paths the spec does not admit.

    An empty list is the only thing that makes a variant runnable. A single
    violation discards it: an implementer that rewrote the evaluator is not
    partially useful, it has invalidated its own result.
    """
    return [path for path in changed_paths(record) if not spec.allows(path)]
```

```python
# ai_experiments/improve/implementer.py
"""Dispatch the work of writing code to an agent, inside a variant.

The planner is a question: it reads a brief and answers with JSON. The
implementer is a *task*: it is pointed at a directory and told to change the
code in it, with its own file tools. So the harness does not grade the reply —
it grades the tree afterwards. An agent that answered beautifully and changed
nothing failed; an agent that said nothing and left a clean, in-scope edit
succeeded.

Scope is checked here and not by the agent's own good behaviour. The one thing
an optimizer must not be able to reach is the number it is optimized on.
"""

from __future__ import annotations

from pathlib import Path
from typing import Any, Callable

from pydantic import BaseModel

from ai_experiments.agents.runner import CliAgentRunner
from ai_experiments.improve.variants import VariantRecord, changed_paths, verify_scope
from ai_experiments.schemas import VariantSpec

#: Argv for agent CLIs running as an implementer: tools enabled, edits applied
#: without a prompt, because nobody is at the keyboard.
IMPLEMENTER_PRESETS: dict[str, list[str]] = {
    "claude": [
        "claude",
        "-p",
        "--output-format",
        "json",
        "--permission-mode",
        "acceptEdits",
    ],
    "codex": ["codex", "exec", "--full-auto", "-"],
}

DEFAULT_IMPLEMENTER_TIMEOUT = 1800


class ImplementerOutcome(BaseModel):
    """What the dispatch produced, and whether the variant may be used."""

    ok: bool = False
    summary: str = ""
    hypothesis: str = ""
    error: str = ""
    changed_paths: list[str] = []
    transcript_dir: str = ""


def dispatch_implementer(
    record: VariantRecord,
    spec: VariantSpec,
    brief: str,
    *,
    command: str = "claude",
    runner_factory: Callable[..., Any] | None = None,
    transcript_dir: Path | None = None,
    timeout_seconds: int = DEFAULT_IMPLEMENTER_TIMEOUT,
) -> ImplementerOutcome:
    """Send the implementer into ``record.root`` and judge what it left."""
    factory = runner_factory or _default_runner_factory(command)
    runner = factory(
        cwd=Path(record.root),
        transcript_dir=transcript_dir,
        timeout_seconds=timeout_seconds,
    )
    result = runner.run(brief, role="implementer")

    payload = result.payload if result.ok else {}
    outcome = ImplementerOutcome(
        summary=str(payload.get("summary", ""))[:4000],
        hypothesis=str(payload.get("hypothesis", ""))[:2000],
        transcript_dir=str(transcript_dir) if transcript_dir else "",
    )

    violations = verify_scope(record, spec)
    if violations:
        outcome.error = (
            "implementer wrote outside its scope: " + ", ".join(violations[:10])
        )
        return outcome

    outcome.changed_paths = changed_paths(record)
    if not outcome.changed_paths:
        outcome.error = (
            "implementer changed nothing"
            + (f": {result.error}" if result.error else "")
        )
        return outcome

    outcome.ok = True
    return outcome


def _default_runner_factory(command: str) -> Callable[..., Any]:
    argv = IMPLEMENTER_PRESETS.get(command)

    def _build(**kwargs: Any) -> CliAgentRunner:
        return CliAgentRunner(
            " ".join(argv) if argv else command,
            **{key: value for key, value in kwargs.items() if value is not None},
        )

    return _build
```

```python
def implementer_brief(
    goal: GoalSpec, summary: dict[str, Any], spec: VariantSpec
) -> str:
    """Tell the implementer what to improve, and what is out of bounds.

    The bounds are also enforced structurally. They are stated here anyway:
    an agent that knows the rule produces a usable variant, while one that
    only gets caught by the check produces a discarded round.
    """
    editable = "\n".join(f"  - {pattern}" for pattern in spec.editable_paths)
    protected = "\n".join(f"  - {pattern}" for pattern in spec.protected_paths)
    return f"""You are improving a machine learning workload, in place, in the
current directory. It is a disposable copy: edit it freely within your scope.

GOAL
{goal.goal}

{_objective_block(goal)}

WHAT HAS BEEN TRIED
{_evidence_block(summary)}

YOUR SCOPE — you may change only files matching:
{editable or "  (nothing: this is a misconfiguration, stop and say so)"}

OUT OF BOUNDS — never edit, and never read as input to a feature:
{protected or "  (none declared)"}
  - the evaluator and anything it imports
  - any test-split data

Changing anything outside your scope discards this variant entirely, so the
work is wasted rather than partially kept.

You cannot report the result. The evaluator runs from a pristine copy of this
project that you cannot reach, and its number is the only one scored. Printing
an IAX_RESULT line from the training code has no effect other than a warning
in the log.

Write the change, then reply with a JSON object:
{{"summary": "what you changed and why", "hypothesis": "why it should help"}}
"""
```

```python
# ai_experiments/improve/lineage.py
"""What a variant changed, kept in a form a person can review.

An improvement nobody can read is not an improvement: it is a number with a
directory attached. The diff answers "what did it do", the transcript answers
"why did it think that would work", and the log ties both to the trials that
measured it.
"""

from __future__ import annotations

import difflib
import json
from pathlib import Path

from pydantic import ValidationError

from ai_experiments.improve.variants import VariantRecord, changed_paths, read_tree

VARIANTS_FILE = "variants.jsonl"


def variant_diff(record: VariantRecord) -> str:
    """Unified diff of the variant against the tree it was copied from."""
    source = read_tree(Path(record.source_dir))
    variant = read_tree(Path(record.root))
    chunks: list[str] = []
    for path in changed_paths(record):
        before, after = source.get(path, b""), variant.get(path, b"")
        try:
            before_lines = before.decode().splitlines(keepends=True)
            after_lines = after.decode().splitlines(keepends=True)
        except UnicodeDecodeError:
            chunks.append(f"--- a/{path}\n+++ b/{path}\nBinary files differ\n")
            continue
        chunks.extend(
            difflib.unified_diff(
                before_lines, after_lines, fromfile=f"a/{path}", tofile=f"b/{path}"
            )
        )
    return "".join(chunks)


class VariantLog:
    """Append-only reader/writer for one campaign's variants."""

    def __init__(self, campaign_dir: str | Path) -> None:
        self.path = Path(campaign_dir) / VARIANTS_FILE

    def append(self, record: VariantRecord) -> None:
        self.path.parent.mkdir(parents=True, exist_ok=True)
        with self.path.open("a") as fh:
            fh.write(json.dumps(record.model_dump(mode="json")) + "\n")

    def read(self) -> list[VariantRecord]:
        if not self.path.exists():
            return []
        records: list[VariantRecord] = []
        for line in self.path.read_text().splitlines():
            if not line.strip():
                continue
            try:
                records.append(VariantRecord(**json.loads(line)))
            except (json.JSONDecodeError, ValidationError):
                continue
        return records
```

```python
    def _should_try_a_variant(self, state: CampaignState, goal: GoalSpec) -> bool:
        """Has the parameter search run out of things to say?

        A search space is a set of answers to a question somebody already
        asked. When more samples from it stop paying, the useful move is to
        change the question — which means changing the code.
        """
        if not goal.variants.enabled:
            return False
        scored = [t for t in state.trials if t.objective_value is not None]
        if len(scored) < goal.variants.stall_rounds + 1:
            return False
        window = scored[-(goal.variants.stall_rounds + 1) :]
        best_before = best_of(window[:1], goal.objective.mode)
        best_after = best_of(window, goal.objective.mode)
        return best_before is not None and best_after is not None and (
            best_after.objective_value == best_before.objective_value
        )

    def _open_variant(
        self, state: CampaignState, goal: GoalSpec
    ) -> VariantRecord | None:
        """Materialize a copy, send the implementer in, and keep it if it is sound.

        Every failure here discards the directory. A half-checked variant that
        stays on disk is one an operator will eventually run by hand.
        """
        campaign_dir = self.campaign_store.campaign_dir(state.campaign_id)
        spec = goal.variants
        source = spec.source_dir or goal.workload.working_dir
        record = materialize_variant(campaign_dir, source, [], spec)

        brief = implementer_brief(goal, summarize_trials(state.trials, goal), spec)
        outcome = dispatch_implementer(
            record,
            spec,
            brief,
            command=goal.agent.command,
            runner_factory=self.implementer_factory,
            transcript_dir=Path(campaign_dir) / "agents" / record.variant_id,
            timeout_seconds=goal.agent.timeout_seconds,
        )
        state.agent_calls += 1

        if not outcome.ok:
            return self._discard_variant(state, record, outcome.error)

        record.diff = variant_diff(record)
        record.edited_paths = outcome.changed_paths
        record.implementer_summary = outcome.summary
        record.hypothesis = outcome.hypothesis
        record.transcript_dir = outcome.transcript_dir

        smoke_check(record, spec)
        if record.smoke_ok is False:
            return self._discard_variant(
                state, record, f"smoke check failed: {record.smoke_output[-500:]}"
            )

        VariantLog(campaign_dir).append(record)
        self.campaign_store.append_event(
            state.campaign_id,
            RunEvent(
                message="variant opened",
                details={
                    "variant_id": record.variant_id,
                    "edited_paths": record.edited_paths,
                    "hypothesis": record.hypothesis,
                },
            ),
        )
        self._rounds(state.campaign_id).append(
            RoundRecord(
                campaign_id=state.campaign_id,
                round=state.rounds,
                stage="apply",
                strategy="variant",
                hypothesis=record.hypothesis,
                rationale=record.implementer_summary,
                outcome={
                    "variant_id": record.variant_id,
                    "edited_paths": record.edited_paths,
                },
            )
        )
        state.active_variant_id = record.variant_id
        return record
```

`data/make.py` genera de forma determinista (`numpy.random.default_rng(0)`) una serie con estructura autorregresiva, y la parte en `train.csv`, `val.csv`, `test.csv`.

## La puerta del spec

Las tareas de arriba cierran cuando los tests pasan. La tesis cierra cuando esto se verifica a mano, corriendo `iax loop` sobre `examples/feature_search` con un agente real:

- [ ] La campaña se estanca en el espacio de parámetros y **abre una variante sin que nadie se lo pida**.
- [ ] El implementador escribe una feature nueva dentro de su scope.
- [ ] Un trial de esa variante entrena desde la copia y evalúa desde el árbol original.
- [ ] El resultado confirmado supera al mejor de las rondas de solo-parámetros.
- [ ] `iax variants diff` devuelve un diff que se puede leer y aplicar al proyecto original.
- [ ] El transcript explica por qué el agente pensó que eso ayudaría.
- [ ] Repetir la campaña con la misma semilla produce un resultado comparable.

Recién después de esto tiene sentido abrir las fases 3 (durabilidad), 4 (Ray completo) y 5 (linaje en producto) del spec. Si la puerta no pasa, lo que falla acá es más informativo que cualquier trabajo de infraestructura hecho por adelantado.

## Lo que este plan no hace

- No ejecuta el implementador en un sandbox. La decisión 6 del spec asume despliegue local confiable; un agente con herramientas dentro de una copia del proyecto del usuario es exactamente tan peligroso como el agente que el usuario ya corre en ese proyecto.
- No paraleliza variantes. Una variante activa por campaña: con dos, la atribución de una mejora deja de ser obvia y el linaje pierde el sentido.
- No transporta artefactos desde Ray. El handoff train→evaluate es local al job (plan 1, Task 9); recuperar el modelo ganador es fase 4.
- No vuelve estructural el borde train/evaluate en Ray. El plan 1 (Task 9) lo defiende con un token por corrida contra un marcador de fase falsificable, que es mitigación, no estructura — ver el addendum a la decisión 2 del spec. Mientras la garantía sea defensiva en Ray, el backend que vale para la tesis es el local.
- No implementa las reservas transaccionales ni el techo duro de wall-clock por intento (el resto de la decisión 7). Acá solo se separa el presupuesto de sesión del de planner; el enforcement por reserva depende de SQLite y es fase 3.
